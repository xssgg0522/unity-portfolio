# 更多玩法 Demo

## 坦克大战与 UGUI 选服面板

### 结构

- `TankBaseObj`：攻击、防御、最大血量、当前血量、炮塔、移动 / 旋转速度
- `PlayerObj`：继承 `TankBaseObj`，处理玩家开火、换武器、受伤更新血条
- `MonsterObj`：继承 `TankBaseObj`，随机路径点巡逻、进入射程后开火、死亡加分和掉落
- `WeaponObj` / `BulletObj`：武器多炮口发射，子弹按 Tag 区分敌我并结算伤害
- `PropReward` / `WeaponReward`：攻击、防御、生命、武器奖励

### UI

- 泛型 `UIManager` + 字典缓存统一管理面板
- `BasePanel` 通过 `CanvasGroup` 做淡入淡出
- `GamePanel` 显示分数、倒计时、血条
- `GameDataMgr` 用 `PlayerPrefs` 保存音乐设置和 Top10 排行榜
- 另含 UGUI 选服面板：登录、注册、服务器选择、输入校验、动态按钮、本地记录持久化

### 设计点

- 用基类统一坦克的伤害和死亡，玩家 / 怪物只写差异
- 怪物 AI 用“随机路径点 + 射程 / 攻击间隔”状态机，不引入行为树
- UI 管理器用泛型 + 字典缓存，面板只关心自己的 `Init`

## 丧尸围城

### 结构

- 3D 塔防：选角 / 解锁英雄、选关卡、造塔点、3 种防御塔与升级链
- `MonsterObject`：`NavMeshAgent` 沿路径进攻中央安全区，按波次刷新
- `TowerObject`：单体 / 群体攻击，按射程和攻击间隔自动索敌
- `MainTowerObject`：中央安全区血量，归零判负
- `GameLevelMgr`：玩家、出怪点、怪物列表、波次统一管理
- `GamePanel`：主塔血量、剩余波次、金币
- `GameOverPanel`：胜负结算金币并返回开始场景

### 设计点

- 波次 / 怪物 / 塔 / 场景 / 角色数据走 JSON 配置，新增内容以配表为主
- 塔和怪物用距离检测和状态机，逻辑简单、可读
- 经济循环：击杀怪物 → 金币 → 建塔 / 升级
